# Compiler Toys 🧸

This repository hosts projects related to Compilers, meant as a learning tool
for me whilst I am reading [Compilers: Principles, Techniques, & Tools](https://suif.stanford.edu/dragonbook/).

- OCaml to LLVM IR compiler front-end: [Oonta](https://github.com/fuad1502/oonta) 🐪
- LR(1) Parser Generator: [JJIK](https://github.com/fuad1502/jjik) 🤢
- Lexer Generator: [JLEK](https://github.com/fuad1502/jlek) 🪞
- *JJIK* example:
[jjik_simple_calculator](https://github.com/fuad1502/compiler_toys/tree/master/jjik_simple_calculator) 🧮
